# Instruções para o GitHub Copilot

## Regras Gerais
- Sempre, antes de gerar qualquer código, forneça uma breve explicação do que será implementado, incluindo lógica e benefícios.
- Adicione comentários explicativos no código, escritos em português, descrevendo funcionalidades e decisões tomadas.
- Faça commits pequenos e padronizados conforme o padrão Conventional Commits, com mensagens em português (ex.: "feat: adicionar funcionalidade X", "fix: corrigir bug Y").

## Linguagem e Estilo
- Use português para comentários, commits e explicações.
- Mantenha o código limpo, legível e seguindo boas práticas da linguagem utilizada.

## Validação
- Após edições, valide o código com builds ou testes quando possível.
- Foque em tarefas relacionadas ao projeto de e-commerce em Java.
